# Brand

- `smith-harness.svg` and `smith-harness-dark.svg`: the README diagram, generated by `generate-diagram.py` from one template with a light and a dark palette, each designed against GitHub's own page backgrounds. Edit the script, not the SVGs.
- The portrait inside the diagram, and the app icon in `assets/`, are composed from the Notionists avatar set by Zoish (CC0 1.0), assembled through the DiceBear API with `assets/compose.py`. The shirt lettering is set in Bradley Hand and converted to outlines.
